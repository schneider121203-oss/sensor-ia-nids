INSTALACION RESUMIDA - SENSOR IA/NIDS FISI
==========================================

VM recomendada
--------------
Ubuntu Server 22.04 LTS, 4 vCPU, 4 GB RAM y 40 GB de disco.
Usar una NIC de gestion y una NIC dedicada al puerto SPAN. La NIC SPAN no debe
tener DHCP, IP ni ruta predeterminada.

Antes de instalar
-----------------
1. Solicitar al datacenter la interfaz de captura y la IP/FQDN del Wazuh Manager.
2. Confirmar TCP/1514 y, si se usa inscripcion automatica, TCP/1515.
3. Confirmar que el Wazuh Manager es igual o mas reciente que el agente.
4. Ejecutar:

   sudo bash scripts/preflight.sh --iface enp0s8 --wazuh-manager 192.168.10.50

Instalacion
-----------
La interfaz es obligatoria y nunca se autodetecta:

   sudo bash install.sh \
     --iface enp0s8 \
     --wazuh-manager 192.168.10.50 \
     --agent-name sensor-ia-nids-fisi

Si el agente Wazuh ya fue instalado por la facultad, agregar
--skip-wazuh-install. El instalador puede ejecutarse nuevamente sin eliminar
evidencia.

Wazuh Manager
-------------
El administrador debe comprobar que los IDs 110001-110004 esten libres,
copiar wazuh_manager_config/custom_rules.xml al directorio de reglas, ejecutar
wazuh-analysisd -t y reiniciar el manager solo en una ventana autorizada.
No se requiere decoder personalizado: el agente usa log_format=json.

Verificacion
------------
   sudo bash scripts/verify_deployment.sh
   sudo systemctl status sensor-ia-nids wazuh-agent
   sudo journalctl -u sensor-ia-nids -f
   sudo tail -f /var/log/ensemble/alerts.json

El sensor usa el modelo v4 congelado, funciona solo con CPU y no bloquea
trafico. Los flujos completos permanecen localmente; Wazuh recibe alertas JSON.
